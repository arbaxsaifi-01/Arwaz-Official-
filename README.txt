Publish with GitHub Pages:
1. Create a PUBLIC repository named USERNAME.github.io (replace USERNAME with your GitHub username).
2. Upload index.html and the assets folder (keep profile.jpg inside assets).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, branch main, folder / (root), then Save.
5. Your site will be at https://USERNAME.github.io after deployment.

Note:
- Replace the Instagram link in index.html with your own profile link.
- The included chat is a demo, not live AI. Never put a secret AI API key in public HTML/JavaScript. A live AI chatbot needs a secure backend.
